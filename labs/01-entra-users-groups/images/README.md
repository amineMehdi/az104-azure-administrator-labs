# Lab 01 Portal evidence

Only screenshots captured from the learner's real Microsoft Entra admin center session are accepted. Do not add mockups, generated Portal images, stock images, or screenshots from another tenant.

Capture after the live validation passes and before cleanup:

1. The filtered users list showing both lab display names and account status.
2. The security group's Overview or Properties page showing its type and lab description.
3. The group's Members page showing cloud user A.
4. The group's Owners page showing cloud user B.

After cleanup, optionally capture Deleted users to demonstrate the recoverable user lifecycle. Keep that image only if it teaches the cleanup behavior and contains no unrelated identities.

Before committing each PNG:

- crop to the relevant blade;
- redact tenant IDs, unrelated users, personal names, domains if sensitive, and browser profile data;
- leave the synthetic lab display names and run ID visible when safe;
- strip EXIF and other metadata;
- record the capture date and applied redactions in `manifest.yml`; and
- verify the Portal labels still match the instructions.

The `portal/` directory intentionally remains empty until an authorized live run is complete.
