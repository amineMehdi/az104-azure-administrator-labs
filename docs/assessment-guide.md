# Assessment authoring guide

Every lab contains exactly ten original four-option, single-answer questions.

## Required mix

- 3 foundational questions
- 5 applied scenario questions
- 2 advanced troubleshooting or design questions

## Files

- `assessment/questions.yml` is the source of truth.
- `assessment/QUESTIONS.md` contains no answers.
- `assessment/ANSWERS.md` explains the correct option and every distractor.

Map every question to objective IDs and current official Microsoft sources. Balance answer positions, avoid trick wording, and never use exam dumps or copied practice questions.
