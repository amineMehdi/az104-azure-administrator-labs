# Build real Azure administration skills

This learning environment combines 28 guided Azure Administrator labs, 1,250
practice questions, architecture diagrams, deterministic validation, and scoped
cleanup. It is designed for learners who want exam readiness and operational
confidence—not a collection of disconnected command snippets.

All Azure operations use Azure CLI hosted in PowerShell. The labs do not depend
on browser-based management procedures, and they are safe-by-default: setup and
cleanup mutations require explicit execution and operate only on recorded lab
resources.

## A complete learning loop

1. Check your [environment readiness](environment-readiness.md).
2. Read the scenario and architecture before running commands.
3. Complete every checkpoint and retain only redacted evidence.
4. Inject, diagnose, and repair the documented fault.
5. Validate the deployment independently.
6. Clean up and confirm that no active managed resources remain.
7. In Labs 01–25, complete the 50-question assessment and review mapped
   remediation. Lab 00 and Capstones 26–27 remain hands-on only.

## Your progress stays private

The site stores progress only in your browser. It has no account, analytics, or
cloud synchronization. Use the [progress dashboard](learner-progress.md) to
export a portable JSON backup or import one you created earlier.

!!! warning "Use a disposable environment"
    Never run a lab in production or in an employer tenant unless the owner has
    explicitly approved the exact changes, cost, permissions, and cleanup plan.
